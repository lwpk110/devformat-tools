# 固定双输入转换器设计

## 背景

现有双向工具通过 Swap 切换方向，输入框与输出框的格式标签随之交换。用户必须先理解当前方向，再决定内容应粘贴到哪一侧，容易造成困绕。已确认的改造方案是固定两种格式的位置，并把两个方向的转换按钮放在输入框中间。

## 交互设计

- 双向工具以第一个 direction 的 `from` 作为左侧格式、`to` 作为右侧格式，页面生命周期内不交换位置。
- 左右文本框均可编辑；用户可在任一侧输入对应格式内容。
- 中间显示两个带完整可访问名称的按钮：左转右与右转左。点击后只读取来源侧并覆盖目标侧。
- 单向生成器仍只有左侧可编辑、右侧只读，中间只显示左转右按钮。
- Load Example 恢复初始方向的左右示例；Clear 清空两侧、错误与最近结果状态。
- Copy 与 Download 操作最近一次成功转换的目标侧；初始状态以右侧示例为最近结果。
- 转换失败时只清空本次目标侧，保留来源侧供用户修正。

## 布局与可访问性

- Desktop 使用“编辑器—方向按钮—编辑器”三列结构，按钮在两个输入框的视觉中线。
- Mobile 使用上下编辑器，中间按钮横向排列；箭头随布局表达真实方向。
- 每个按钮的 `aria-label` 包含完整格式名称，例如 `Convert JSON to YAML`。
- 保持现有 stone/teal 色彩、等宽编辑器、可见 focus ring 和本地处理提示。

## 验收

- 双向工具不再显示 Swap。
- 两侧格式标签固定且文本框均可输入。
- 两个方向分别调用正确 converter，并只更新目标侧。
- 单向工具仍禁止编辑输出。
- Copy、Download、错误、示例与清空行为适配最近转换方向。
- Component tests、Astro check、完整 tests 与 production build 全部通过。
