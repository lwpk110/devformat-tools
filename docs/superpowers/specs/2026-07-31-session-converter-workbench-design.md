# ChatGPT Session Converter 批处理工作台设计

## 目标

面向经常批量转换 ChatGPT session 的运维/开发用户，重排页面信息层级，让导入、格式选择、转换结果和下载成为首屏主流程，同时保留现有六种输出格式、本地处理和 JSON 复制能力。

## 设计

- 页面首屏保留简短标题和隐私提示，减少说明内容对工具区的挤压。
- 工具区采用批处理工作台结构：顶部是输出格式切换与输入来源操作，中间是输入/结果双栏，底部是转换选项。
- 输入面板明确支持粘贴单个/数组 JSON 和多文件上传，并在导入后显示文件或账号处理反馈。
- 结果面板先展示成功数、跳过数、目标格式和账号列表；JSON 文本作为可复制的详情输出。
- 下载按钮根据结果自动显示 `下载 JSON` 或 `下载 ZIP`，没有可下载结果时禁用。
- 桌面端保持双栏，窄屏切换为单栏；按钮、状态文本和表格保留键盘可访问的语义状态。
- 保持现有 stone/teal 视觉语言，不新增依赖，不改变转换引擎与输出格式契约。

## 交互与状态

- 粘贴或上传内容后自动转换，成功时显示账号数量和跳过数量。
- 解析失败或没有可转换 session 时，输入区显示可读错误，结果保持为空。
- 切换格式或选项后立即刷新结果；批量 CPA 结果下载为 ZIP，其余结果下载为 JSON。
- 清空操作同时清除输入、结果、统计和状态反馈。

## 验收标准

1. 高频批量用户能在首屏完成格式选择、粘贴/上传、确认结果和下载。
2. 成功与跳过数量、账号列表和当前格式在结果区清晰可见。
3. 复制、下载、示例、上传和清空在无结果时具备合理禁用或反馈状态。
4. 桌面和移动布局没有横向溢出或文本重叠。
5. 所有转换仍在浏览器内完成，现有转换单元测试和项目质量命令通过。

## 非目标

- 不修改 session 转换算法、输出结构或支持的格式。
- 不增加后端接口、持久化、登录或 Cloudflare 发布流程。
